# Episode 001 Preview
## Volatco B at J7 polyForth Bring-up

### Preview Hook
Before the forest creatures can build useful Forth programs, they must solve a practical first challenge: make the Volatco B polyForth path reliable enough to trust.

If this step fails, they lose daylight, lose confidence, and lose time they need for real field decisions.
If this step succeeds, they gain a shared technical foundation for every future episode.

### What This Episode Shows
- Why `VOLATCO-B` at `921600` is mission-critical
- How the team verifies profile and status before attach
- How they confirm live readiness with an `ok` response
- How they stress-test reset/reconnect so success is repeatable
- How they turn one expert workflow into shared team knowledge

### Technical Milestones (Visible In Story)
1. `./scripts/monitor.sh profiles`
2. `./scripts/monitor.sh status`
3. `./scripts/monitor.sh attach B`
4. Enter key returns `ok`
5. Reset/reconnect still returns `ok`
