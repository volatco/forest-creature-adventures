# Funding Campaign Plan

## Goal
Fund production of the Forest Creature Adventures episode series as a practical storytelling + technical education project focused on Volatco and aeonForth workflows.

## Campaign Positioning
This is not only an art project and not only a technical project.
It is a bridge between:
- practical computing education (repeatable workflows, understandable systems), and
- narrative learning (cooperation, resilience, friendship, and autonomy).

## Primary Audience Segments
1. Open hardware and Forth communities
People who value understandable systems and educational tooling.

2. Indie education supporters
Backers who support practical learning projects with clear social value.

3. Story/comic/animation supporters
Backers motivated by character-driven series with strong worldbuilding.

4. Philosophy-of-technology supporters
People drawn to themes of autonomy vs opaque external systems.

## Funding Narrative
Core message:
"We are building a story world where woodland hunter-gatherers learn to master understandable computing systems, so they can make better decisions about their lives, environment, and future."

Practical stake:
- Without reliable tooling, they lose daylight, field reliability, and confidence.
- With reliable tooling, they can create meaningful Forth programs and share knowledge.

## Platform Strategy
Use one primary platform plus optional mirrors.

Recommended primary options:
1. GoFundMe
Best when you want straightforward support with minimal reward complexity.

2. Kickstarter
Best when you want milestone-based all-or-nothing delivery and structured reward tiers.

3. Patreon or Ko-fi
Best for ongoing episode cadence and recurring support.

Suggested sequence:
1. Start with one-time raise (GoFundMe/Kickstarter style) for first production block.
2. Transition to recurring platform (Patreon/Ko-fi) for sustained episode pipeline.

## Funding Target Framework
Define an initial target that covers one production season (for example 4-8 episodes), not the whole universe.

Budget categories to include:
- Episode art generation and post-processing
- Writing/editing and prompt continuity work
- Technical validation and hardware workflow capture
- Assembly/publishing assets (comic pages, GIFs, docs)
- Platform/payment processing buffer
- Contingency reserve

## Deliverable Structure
Backers should understand exactly what completion means.

Suggested deliverable bundle for first funding block:
1. Completed Episode 001-004 panel sets
2. Final compiled comic pages + GIFs per episode
3. Public episode notes with technical success signals
4. Development log posts (what worked, what changed, what failed)

## Reward / Recognition Model
If using reward tiers, keep fulfillment light and digital-first.

Possible tiers:
- Supporter: name in thank-you list
- Early Reader: early access to episode drafts
- Field Guide Backer: behind-the-scenes prompt + script evolution notes
- Lore Backer: vote on side-character mini-episodes
- Founding Circle: quarterly live Q&A + roadmap input

## Campaign Timeline
Pre-launch (2-3 weeks):
- finalize page copy
- prepare visual assets (hero image, sample panels, progress screenshots)
- line up first-day supporters

Launch (30 days):
- day 1 announcement burst
- twice-weekly updates
- one technical deep-dive update
- one story/lore update

Post-campaign (90 days):
- ship first content block on fixed cadence
- publish transparent progress tracker

## Trust and Credibility Signals
- Show current repository structure and active episode artifacts
- Show exact workflow pipeline (`generate_episode.py`, episode folders, checklists)
- Define completion criteria clearly
- Provide realistic scope for first funding block
- Publish what will happen if funding exceeds target (stretch priorities)

## Risk Management (State Up Front)
Main risks:
- production throughput variability
- creative iteration overhead
- technical validation delays

Mitigations:
- episode-by-episode release model
- strict definition-of-done checklist
- transparent public updates

## Launch Checklist
1. Final campaign copy approved
2. Budget table filled with real numbers
3. Episode 001 preview visuals prepared
4. 60-90 second pitch video/script drafted
5. FAQ prepared
6. Update cadence calendar prepared
7. First-week outreach list ready

## Success Metrics
- Funding achieved target for first production block
- Backer conversion rate from community outreach
- Delivery cadence adherence
- Backer retention into recurring support phase
